# Milestones

- [ ] **M0 — Foundation:** identidade, componentes, páginas estruturais, qualidade, Docker e documentação. Implementação inicial versionada; aguarda validação de build, testes e visual.
- [ ] **M1 — Conteúdo e lançamento:** fichas reais de projetos, artigos Markdown, SEO e produção.
- [ ] **M2 — Ferramentas e laboratório:** demonstradores e utilitários.
- [ ] **M3 — Expansão:** busca e automação conforme demanda.

## Aceite M0

`npm run typecheck`, `npm run lint`, `npm run test`, `npm run build` e `docker compose build` devem concluir com sucesso. Validar visualmente em mobile/desktop e navegação por teclado. Não marcar como concluído sem evidências.
