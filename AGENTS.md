# Instruções para agentes — ULLN

Leia `docs/ARCHITECTURE.md`, `docs/DESIGN_SYSTEM.md` e `docs/MILESTONES.md` antes de editar. Preserve React + Vite + TypeScript strict, CSS Modules e tokens semânticos. Não adicione backend, banco, login ou CMS sem decisão documentada. Execute lint, typecheck, testes e build após mudanças. Nunca declare testes como aprovados sem executá-los. Evite alterar domínio, tunnel ou deploy de produção sem solicitação explícita. Documente decisões e mantenha o conteúdo factual, sem métricas inventadas.
